## 1. 产品概述

### 1.1 产品定位

CAE Claw 是一个面向 CAE（计算机辅助工程）领域的 AI Agent 平台，旨在通过人工智能技术降低 CAE 软件的使用门槛，提升工程师的工作效率。

**核心价值**：
- 将复杂的 CAE 操作封装为可配置的 AI 能力
- 通过自然语言或可视化编排，让非专业用户也能完成专业分析
- 支持多 CAE 软件（ANSA、HyperWorks 等）的统一接入

### 1.2 目标用户

| 用户类型 | 需求 | 使用场景 |
|----------|------|----------|
| **CAE 工程师** | 自动化重复工作、提升效率 | 批量处理参数化分析 |
| **设计工程师** | 快速获取 CAE 结果 | 设计验证、快速迭代 |
| **项目经理** | 了解项目进度 | 监控分析任务状态 |
| **AI 开发者** | 扩展 CAE 能力 | 开发自定义 Skill/Workflow |

## 3. 功能需求

### 3.1 AI Agent 引擎

#### 3.1.1 核心能力

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 自然语言理解 | 解析用户输入，提取意图和参数 | P0 |
| 任务规划 | 将复杂任务分解为可执行步骤 | P0 |
| 工具调用 | 调用 Skill/Workflow 执行任务 | P0 |
| 记忆管理 | 短期会话 + 长期知识存储 | P1 |
| 多轮对话 | 支持上下文连贯的多轮交互 | P1 |
| 容错处理 | 自动重试、优雅降级 | P1 |

#### 3.1.2 Agent 执行流程

```
用户输入
    │
    ▼
┌────────────────────────────────────────────┐
│           1. Intent Understanding           │
│         理解用户意图，提取关键信息            │
└────────────────────┬───────────────────────┘
                     │
                     ▼
┌────────────────────────────────────────────┐
│              2. Task Planning               │
│          分解任务，选择合适的执行路径         │
│                                            │
│   "静力学分析" → [导入几何] → [生成网格]    │
│                  → [施加边界] → [求解] → 后处理 │
└────────────────────┬───────────────────────┘
                     │
                     ▼
┌────────────────────────────────────────────┐
│             3. Execution                    │
│           按计划执行 Skill/Workflow         │
│                                            │
│   Skill A ──► Skill B ──► Skill C           │
└────────────────────┬───────────────────────┘
                     │
                     ▼
┌────────────────────────────────────────────┐
│              4. Result Review              │
│           检查结果，决定是否需要调整          │
└────────────────────┬───────────────────────┘
                     │
              ┌──────┴──────┐
              │  成功?       │
              └──────┬──────┘
           是           否
            │           │
            ▼           ▼
         返回结果    重新规划
```

#### 3.1.3 LLM 模型支持

| 模型类型 | 支持的模型 | 用途 |
|----------|------------|------|
| 云端 API | GPT-4o, GPT-4o-mini, Claude-3.5-Sonnet, Gemini | 通用推理、代码生成 |
| 本地部署 | Ollama + Llama/DeepSeek/Qwen | 离线使用、成本控制 |
| 专用模型 | DeepSeek-Coder, CodeLlama | 代码相关任务 |

| `run_script` | 同步执行脚本 | session_id, script, timeout | result |
| `run_script_async` | 异步执行脚本 | session_id, script | task_id |
| `get_task_result` | 获取任务结果 | task_id | result |
| `list_files` | 列出文件 | directory, pattern | file_list |
| `read_file` | 读取文件 | file_path | content |
| `write_file` | 写入文件 | file_path, content | success |
